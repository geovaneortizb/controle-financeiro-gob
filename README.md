# Controle Financeiro — PWA

Projeto pronto para publicação como PWA.

## Publicação gratuita no GitHub Pages

1. Crie uma conta em https://github.com/ (se ainda não tiver).
2. Crie um repositório público, por exemplo `financas`.
3. Envie todos os arquivos desta pasta para o repositório, mantendo a pasta `icons`.
4. No GitHub, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde a publicação.
8. O endereço será parecido com:
   `https://SEU-USUARIO.github.io/financas/`

## Instalação

### Android
Abra o endereço no Chrome. Quando aparecer a opção de instalação, use-a. Também pode usar o menu do navegador → **Instalar aplicativo**.

### iPhone
Abra o endereço no Safari → **Compartilhar** → **Adicionar à Tela de Início**.

## Offline

Depois de carregado e instalado, o service worker mantém o aplicativo disponível offline. Os lançamentos ficam no armazenamento local do aparelho.

## Backup

Use **Exportar backup** antes de trocar de aparelho. No novo aparelho, abra o app e use **Restaurar backup**.

## Observação importante

Este projeto não possui sincronização em nuvem. Os dados ficam no dispositivo/navegador. Para ter os mesmos lançamentos automaticamente no computador e no celular, será necessário adicionar autenticação e um banco de dados online.
